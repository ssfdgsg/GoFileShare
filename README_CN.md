# GoFileShare - 局域网文件共享系统

一个简单、轻量的文件共享系统，专为局域网环境设计，无需复杂配置即可快速部署。

## ✨ 特性

- 🚀 **零配置部署** - 下载即用，无需安装数据库
- 📁 **完整的文件管理** - 上传、下载、删除、搜索文件
- 🔍 **文件搜索** - 快速查找文件
- 📱 **响应式界面** - 支持桌面和移动设备
- 🌐 **局域网访问** - 自动显示局域网IP地址
- 💾 **SQLite存储** - 轻量级数据库，无需额外安装
- 🔐 **无登录系统** - 简化使用流程
- 🎨 **现代化UI** - 美观易用的界面设计

## 📋 系统要求

- 操作系统：Windows / Linux / macOS
- Go 1.24+ (仅编译时需要)
- 磁盘空间：50MB 以上

## 🚀 快速开始

### 方法一：使用预编译版本（推荐）

1. 从 Releases 页面下载适合您系统的版本
2. 解压到任意目录
3. 运行程序：
   - **Windows**: 双击 `gofileshare.exe`
   - **Linux/macOS**: `./gofileshare`
4. 在浏览器中打开显示的地址

### 方法二：从源码编译

```bash
# 克隆项目
git clone <repository-url>
cd GoFileShare

# 编译
go build -o gofileshare .

# 运行
./gofileshare
```

## 💡 使用说明

### 启动服务

运行程序后，终端会显示访问地址：

```
==========================================
🚀 GoFileShare 文件共享服务已启动
==========================================
本地访问: http://localhost:8080

局域网访问地址:
  http://192.168.1.100:8080
==========================================
```

### 局域网访问

1. 确保所有设备连接到同一个局域网
2. 在其他设备的浏览器中输入显示的局域网IP地址
3. 即可访问文件共享系统

### 文件操作

- **上传文件**: 点击"上传文件"按钮，或直接拖拽文件到上传区域
- **创建文件夹**: 点击"新建文件夹"按钮
- **下载文件**: 点击文件右侧的"下载"按钮
- **删除文件/文件夹**: 点击"删除"按钮
- **搜索文件**: 在搜索框输入关键词，按回车搜索

## 📂 目录结构

```
GoFileShare/
├── data/              # SQLite 数据库文件（自动创建）
├── FileStore/         # 上传的文件存储目录（自动创建）
├── config/            # 配置代码
├── controllers/       # 控制器
├── models/            # 数据模型
├── routes/            # 路由配置
├── views/             # HTML 模板
└── main.go            # 程序入口
```

## 🔧 高级配置

### 修改端口

编辑 `main.go` 文件中的端口配置：

```go
if err := r.Run("0.0.0.0:8080"); err != nil {
```

将 `8080` 改为您需要的端口号。

### 修改文件存储路径

编辑 `config/storage.go` 中的 `RootPath` 变量。

## 🛡️ 安全提示

- 本系统设计用于**局域网环境**
- **不建议**将服务直接暴露到公网
- 如需公网访问，请配置：
  - 防火墙规则
  - 反向代理（如 Nginx）
  - HTTPS 证书
  - 访问控制

## 🐛 常见问题

### Q: 启动后无法访问？
A: 检查防火墙是否允许程序访问网络，确保端口8080未被占用。

### Q: 局域网其他设备无法访问？
A: 
- 确保所有设备在同一局域网
- 检查防火墙设置
- 尝试关闭防火墙测试

### Q: 上传大文件失败？
A: 检查磁盘空间是否充足。

### Q: 数据库文件在哪里？
A: 在 `data/files.db` 文件中。
